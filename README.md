Street Art Dreams – Location Management
Project Overview
Street Art Dreams is a collaborative college web development project designed to help street designed to help street performance locations through an interactive map.
The project explores location-based services, interactive mapping, and web application development.
Features

Interactive Map: Uses Leaflet.js and OpenStreetMap to display locations.
Location Selection: Allows users to select locations on a map and capture latitude and longitude.
Location Details: Provides fields for location names, coordinates, and performance radius.
Performance Categories: Includes music, dance, drama, and art.
Performance Duration: Allows users to specify performance duration in minutes.
Reservation Options: Includes reservation and queue selections.
Location Management: Provides controls for saving, clearing, and deleting location information.

Technologies Used
HTML  CSS  JavaScript  Leaflet.js  OpenStreetMap  PHP integration (backend code not included in this repository)
Project Background
Street Art Dreams was developed as a collaborative college group project. It provided an opportunity to explore web development, interactive mapping, and location-based application design.
Project Status
This repository contains the location-management interface. Some functionality, including backend integration and location management operations, may require additional implementation or testing.
